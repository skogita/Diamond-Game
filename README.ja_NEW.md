# ダイヤモンドゲーム — 本の付属ソース

[English](README.md)

『**LLM で 100 万行のソフトウェア開発 IV — ダイヤモンドゲームの打ち手を作る**』（4 巻）で作った、アプリ「ダイヤモンドゲーム」の設計書とコードです。

3 人で遊ぶダイヤモンドゲーム（星形の盤・181 升・各自 15 個の駒・うち 1 個がキング）。各席は「人」か「計算機」を選べます。計算機の打ち手は 14 段あり、1 段ずつ工夫を足していきます（読み・記録から学んだ重み・モンテカルロ木探索・易しい深層学習）。

## ダウンロード

**すぐ動くアプリは [Releases](../../releases) にあります**（このリポジトリの中ではありません）。

| ファイル | 中身 |
|:---|:---|
| `diamond.zip` | **日本語版。**設計書と画面が日本語。Windows のインストーラと Android の APK（版 1.69.1） |
| `diamond_en.zip` | **英語版。**設計書・README・画面が英語（コードのコメントは日本語のまま）。中の並びは同じ |

アプリは**署名していない**ので、Windows と Android が警告を出します（Windows は「詳細情報」→「実行」、Android は「提供元不明のアプリ」を許可）。

## ZIP の中身

| 場所 | 中身 |
|:---|:---|
| `prebuilt/windows/diamond-flutter-setup.exe` | Windows のインストーラ。ダブルクリックで入れる |
| `prebuilt/android/diamond-flutter.apk` | Android のアプリ（リリース版） |
| `docs/` | 設計書（DD）22 本と、RF・CR の一覧 1 本。L1〜L4 |
| `requirements/` | 要求・RF（9 件）・CR（50 件・CR-17〜CR-69）。開発の記録（DB）から書き出したもの |
| `src/flutter/` | アプリの Dart のコード（Flutter・Windows と Android） |
| `src/learn/` | 記録から重みや網を学ばせる Python |
| `src/installer/` | Windows のインストーラを作る道具 |
| `experiments/` | 本の §7.13・§7.14 の実験（読まない打ち手）の設計書と道具のコード。アプリの本体ではない |
| `LICENSE`・`LICENSE-DOCS.md` | 利用条件（下） |

入れていないもの: 試験のファイル、データベースそのもの、本のファイル、組みの出力、`local.properties`。

## 規則

始める窓の既定は日本（ダイヤモンドゲーム）です。キングは最後にゴールの◎（トップ）に入って上がります。版 1.69.1 で、一般ルールの既定もこの決まりに直しました（CR-69）。
